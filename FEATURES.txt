====================================================================
  SpellX — Complete Feature List
====================================================================
A mobile-first, dependency-free web game that teaches the 850 words
of Ogden's Basic English to Hindi-speaking learners.

--------------------------------------------------------------------
 CORE PURPOSE
--------------------------------------------------------------------
- Teaches the 850 words of Ogden's Basic English to Hindi speakers
- Also ships a playable 53-topic English grammar course (7 sections,
  530 practice activities, 265 example sentences, copy-ready AI tutor prompts
  for every lesson that tailor practice to learner confidence, context, and challenge)
- Combined Words + Grammar AI practice builds a copy-ready tutor prompt from
  one vocabulary category and grammar chapter; the external AI tutor chooses
  words from the category and adapts the practice to learner performance
- English Reading offers six original passages across Beginner, Intermediate
  and Advanced levels, on-demand Hindi word/sentence help, speech playback,
  comprehension and vocabulary exercises, saved words and progress
- Mobile-first, zero dependencies (vanilla HTML/CSS/JavaScript)
- No app-initiated external calls — lessons and learning data are local
- Runs by double-clicking index.html from file:// (no server needed)
- Installable PWA + offline lessons and learning data (service worker over http/https)
- Saffron English design system: saffron/amber primary, emerald +
  indigo accents, tactile 3D-lip controls, light + dark themes
- System fonts + emoji/SVG icons only (no remote fonts/CDNs or assets)
- English-only UI chrome; word content (Hindi/Devanagari/examples)
  kept verbatim from the dataset

--------------------------------------------------------------------
 NAVIGATION (5-tab bottom bar)
--------------------------------------------------------------------
- Home     - dashboard: goal ring, mastery, mode grid, Continue
- Learn    - flashcard session (category picker + cards)
- Spelling - tile puzzle
- Quiz     - 4-option rounds
- Review   - spaced repetition, with a due-count badge
- Grammar, English Reading, Stats, Listening, Typing and Settings are reached from
  the Home mode grid and the header profile (settings) button.
  (A 6th tab does not fit a 360 px phone, so Grammar stays on Home.)

--------------------------------------------------------------------
 MODES — 11 LIVE
--------------------------------------------------------------------
Home
  - Streak counter, daily-goal progress ring
  - Overall 850-word progress
  - Per-category mastery chips
  - "Continue" CTA that resumes the last mode

Learn (Flashcards)
  - Flip cards: front = English word + pronunciation (Devanagari + IPA)
  - Back = Hindi + English meanings and both example sentences
  - Tap / swipe / Enter to flip; "Again" / "Know it" buttons
  - "Know it" seeds the SRS schedule

Quiz
  - 4-option multiple choice, 10 per round
  - 4 variants: English->Hindi, Hindi->English, Audio->meaning,
    Fill-the-blank
  - Smart distractors (same category + difficulty, never repeat)

Listening
  - Word played via en-US SpeechSynthesis, pick the meaning
  - Replay orb
  - Hidden gracefully if no English voice is available

Typing
  - Given the Hindi meaning, type the English word
  - Case-insensitive, trimmed, tolerant of "/" variants
  - Diff-style correction on failure

Spelling Puzzle
  - Choose Relaxed practice (untimed) or a Timed challenge
    (the harder-word timer awards a bonus but never ends the round)
  - Build the word letter-by-letter from shuffled tiles
  - 3 equivalent input paths:
      * Drag a tile onto a slot
      * Tap a tile to place it, including an incorrect guess to practice from
      * Type on a physical keyboard (letters + Backspace / arrows)
  - After a miss, keep correctly positioned letters and return the rest
    to the tray for a supported retry
  - Difficulty ramp: (1) letters only, (2) +2-3 decoys,
    (3) hide the English gloss (Hindi-only),
    (4) hardest words with a soft 60s bonus timer in timed mode
  - Hints cost XP and never block (hear it / first letter /
    English meaning / example sentence)
  - Free "Show word" reveal button when stuck (0 XP, marks seen)
  - Clean solve promotes one SRS box; two wrong completions queue
    the word into Review
  - Session summary reports solved, revealed, and Review words
  - Success card shows the word, pronunciation, and both examples

Review
  - Leitner / SM-2-lite: 6 boxes, intervals 0/1/2/4/8/16 days
  - Correct -> up a box; wrong -> box 0 and re-queued in session
  - Only due cards appear; tab shows the due count

Stats
  - Per-category mastery
  - 14-day accuracy sparkline
  - Words due, longest streak, level/XP
  - Confirm-guarded reset

Settings
  - Hindi-first vs English-first prompts
  - Reviewed Hindi grammar help (off by default; unreviewed translations stay hidden)
  - TTS voice + rate
  - Sound on/off
  - Daily goal size (10 / 20 / 30 / 50)
  - Reset

Grammar
  - 53 topics in 5 levels across 7 sections (chapter data numbered 0–6)
  - Level list -> topic (optional relevant rule/pattern card, English summary,
    3 key points, keywords, 5 examples) -> practice
  - Rule cards appear only when a lesson has a useful, relevant rule or
    pattern; their examples and forms are specific to that topic
  - 530 practice activities (10 per topic): chooser, cloze, word-order,
    spot-the-mistake, and self-assessed sentence production
  - Every practice item includes a matching line from its lesson's Ravi story
    as a clue for applying the same lesson concept
  - Hindi help is hidden by default and only shown when enabled and
    explicitly marked reviewed; lesson stories are withheld until their
    English scenes are checked against the lesson topic
  - One data file per topic under data/grammar/, so any single topic
    can be edited without touching the others
  - Session = 10 items mixed across the level, instant feedback
  - Keyword chips cross-link into the 850-word deck (pronunciation,
    Hindi meaning, examples) when the keyword is a Basic English word
  - Words + Grammar practice combines a selected grammar topic with 3–5
    words, meanings and examples from the 850-word list in one AI tutor prompt
  - Combined prompts use topic-specific rules only when present and guide
    the external AI tutor to practise one question at a time with adaptive feedback
  - Mastery per topic (done at 6 correct), +12 XP per correct answer
  - Grammar progress rides in the same "b850:v1" save, migrates old
    saves safely, and never touches the 850-word seen/learned maps

English Reading
  - Six original passages across Beginner, Intermediate and Advanced;
    everyday stories, workplace email, software work, interviews and a
    fictional news-style explainer
  - Read the full passage or one sentence at a time, adjust text size and
    speech speed, and reveal Hindi translations/simple explanations on demand
  - Click words for Hindi meaning, simple English definition, pronunciation,
    an example and optional save to a personal vocabulary list
  - en-US SpeechSynthesis reads sentence-by-sentence and highlights the
    current sentence; unavailable audio falls back to text
  - Four activities per passage: comprehension multiple choice, fill-in
    the blank, vocabulary meaning and sentence ordering; progress, best
    score and answers persist
  - Optional browser speech recognition compares recognized words with one
    sentence; the result is explicitly not a pronunciation-accuracy score.
    Browser speech services may process audio; SpellX does not store recordings.
  - Optional copy-ready tutor prompt; no live AI or external API calls

--------------------------------------------------------------------
 GRAMMAR COURSE (53 topics, 5 levels, 7 sections) — LIVE
--------------------------------------------------------------------
- data/grammar/ holds one file per topic, plus chapters.js, the
  supplementary chapter-six data, story-scenes.js, and index.js. Each topic
  file is a classic script that pushes its own object onto
  window.GRAMMAR_TOPICS, so load order does not matter and a missing
  file cannot scramble the others. story-scenes.js supplies one
  continuous Ravi narrative with a scene matched to each lesson;
  index.js loads last and rebuilds
  the two arrays the app already uses (grammarTopics and
  grammarExercises), so the screen, the store and the tests needed no
  change for the split.
- Topic fields (inside each t*.js file):
    id, topic (slug), title, titleHindi, level (1-5), levelLabel,
    keywords[], summary, optional explanationHindi, points[3],
    optional rules {pattern, forms[], exceptions, optional hindiTip},
    examples[5] {en, optional hi, note}, exercises[10],
    English story scene[4] and recap are provided in story-scenes.js;
    each scene records its lesson id, rule focus and review status,
    optional modalGuide / verbFormGroups / studyGuide /
    pronunciationGuide references,
    sourceOrder, source
- Coverage by level:
    Level 1 — Basic Grammar        11 topics (including pronunciation)
    Level 2 — Making Sentences      8 topics (subject/predicate .. modals)
    Level 3 — Tenses               10 topics (including V1/V2/V3 verb forms)
    Level 4 — Important Grammar     8 topics (prepositions .. question words)
    Level 5 — Speaking, writing and spelling 16 topics
  Total 53 topics, including modal verbs, V1/V2/V3, pronunciation
  and six spelling/writing topics in the seventh section.
- Planned learning loop per topic:
    * Learn card: summary + keyword chips; every keyword that also
      exists in the 850-word dataset is cross-linked, so tapping
      "under" opens its pronunciation, Hindi meaning and example
    * Practice: choice, cloze, word order, error-spotting and
      self-assessed writing tasks that require learner-produced text
    * Hindi help is optional; unreviewed translations are not displayed
    * Mastery: seen / correct / wrong per topic, same XP curve as
      the word modes (10 + 5 x difficulty), same streak and goal
    * Level progress bar + "next topic" CTA on Home
    * Level 5 speaking topics link out to Typing + TTS practice
      using that topic's keywords as the deck
- Storage: extends the single "b850:v1" state with a `grammar` map,
  migrating old saves safely (missing keys default, never crash).
- Grammar references also render the modal-verb guide and all 76
  V1/V2/V3 forms from the supplied study material.

--------------------------------------------------------------------
 GAMIFICATION
--------------------------------------------------------------------
- XP per correct answer (10 + 5 x difficulty)
- Square-root level curve
- Day-based streak (one missed day keeps it, >=2 days restarts)
- Daily goal with progress ring (counts all answers, non-punitive)
- Confetti celebration on goal / level completion
- No lives, no punitive timers, no countdown pressure

--------------------------------------------------------------------
 SPEECH (TTS)
--------------------------------------------------------------------
- window.speechSynthesis with an explicit en-US voice
- Handles the async voiceschanged event (plus a Safari poll)
- Cancels any in-flight utterance before a new one
- Graceful degradation: audio hidden / falls back to text if no
  English voice is available

--------------------------------------------------------------------
 ACCESSIBILITY
--------------------------------------------------------------------
- Semantic HTML, real <button> elements
- aria-live="polite" feedback region
- Visible focus rings, accessible names on icon-only controls
- Full keyboard play: 1-4 options, Enter/Space flip-advance,
  Esc back, arrows + Backspace in Spelling
- Drag is never the only input (tap + keyboard remain)
- Colour is never the only signal (check/cross icons + text)
- Respects prefers-color-scheme (light + dark) and
  prefers-reduced-motion (animations + confetti disabled)
- Text never under 15 px; touch targets >= 44x44 px

--------------------------------------------------------------------
 OFFLINE / PWA
--------------------------------------------------------------------
- manifest.webmanifest makes the app installable (portrait, SVG icon)
- sw.js precaches the app shell + dataset, stale-while-revalidate
- After the first load, works with the network disconnected
- No app-initiated runtime network calls: no analytics, AI APIs, fonts, or images
  (inline SVG, emoji, CSS only)
- Reading passages, progress and dictionary data are local; the optional
  browser speech-recognition service is browser-managed and may use network

--------------------------------------------------------------------
 ARCHITECTURE / DATA
--------------------------------------------------------------------
- One global namespace: window.B850
- Classic scripts (no ES modules) so file:// works
- Screens are registered dynamically: B850.screens.<id>.render()
  (so a new mode needs no router change, only a script tag)
- Read-only datasets, normalised on boot (handles plough/plow
  variants, defensive field guards):
    data/words.js    - 850 words (pronunciation, EN + HI glosses,
                       two example sentences each)
    data/reading.js  - original leveled English reading passages and exercises
    data/grammar/    - 47 topic files (t01..t47), each self-registering
                       on window.GRAMMAR_TOPICS, plus index.js which
                       derives grammarTopics + grammarExercises
- Single versioned localStorage key "b850:v1"
- State survives reload, tab backgrounding, and browser restart
- Tolerant of corrupt or older saves (never crashes)
- Data: Ogden's Basic English (public-domain word list) +
  user-supplied Hindi glosses / Devanagari / examples; grammar
  topics from the user-supplied grammar curriculum and verb-form guides

 IMPLEMENTATION PLAN — GRAMMAR COURSE

Goal: turn the split data/grammar/ files into a playable grammar course without
touching the word dataset and without adding dependencies or a build
step.

STATUS: Phases 0, 1, 2, 3 and 4 are DONE. The optional Phase 3 SRS
  hand-off is deliberately deferred (see KNOWN LIMITS).
  - Phase 0: 53 topics x (5 examples + 10 exercises) = 265 example
    sentences and 530 exercises, with 3 rule points per topic.
  - Phase 1: script tags, BRAND map, state.grammar + migration, SW
    precache (cache b850-v8), Home grammar card with progress.
  - Phase 2: js/modes/grammar.js renders levels -> topic -> practice

  - Phase 3: Stats gained a Grammar block (5 level rows with done

  - Phase 4: one suite, test/course.test.js (49/49), runs the real app

PHASE 0 — Content (dominant cost, do this first)
  - Add per-topic example sentences to the data (3-5 per topic,
    235 sentences), each with:
        { en: "...", hi: "Devanagari translation", note: "why" }
  - Add exercises for the 4 planned types, stored pre-computed (no
    build step, no runtime generation guesswork):
      A. chooser  - "Which sentence is correct?" 3 options, 1 right
      B. order    - scrambled word array + the answer string
      C. cloze    - sentence with a blank + 4 keyword options
      D. spot     - a wrong sentence + the corrected version
  - Keep sentences inside the 850-word Basic English vocabulary
    wherever possible. This doubles as a testable quality bar: scan
    every example for words outside the dataset and fix or justify.
  - Hindi must be natural Devanagari, same style as the word data.
  - Split storage if grammar.js grows past ~40 KB raw: keep topics
    in data/grammar.js and put sentences/exercises in
    data/grammar-exercises.js (adds one <script> tag, nothing else).
  - Decision needed: hand-write, or AI-draft then human-review.
    AI drafting is fine for English; Hindi must be reviewed by a
    Hindi speaker before shipping.

    and a Home card showing level progress + "next topic".
  - Bottom tab bar stays at 5 items. Grammar opens from Home.

PHASE 2 — Screens (1.0 - 1.5 days)

KNOWN LIMITS
  - The SRS hand-off (grammar mistakes becoming Review cards) is
    deferred: Review resolves every queued id through data/words.js,
    so mixing grammar ids into that queue needs a Review change and
    its own tests. Nothing else depends on it.
  - 363 distinct words in the grammar content fall outside the
    850-word list (park, cricket, finished, were, plays ...) across
    the examples, exercises and rule sentences. Basic English cannot
    express every
    grammar rule, so this is accepted and reported rather than hidden.
  - Exercise instruction text ("Which sentence is correct?" etc.) is
    English UI chrome and is excluded from that count.

====================================================================
 What this is NOT
====================================================================
- No backend, no accounts, no network. Everything is on-device.
- The dataset is read-only; no words are invented or edited.
- No alert()/confirm() in the game loop (in-page sheets only).
- Grammar is data-only right now: it is not reachable in the UI and
  nothing loads it until Phase 1 is done.
